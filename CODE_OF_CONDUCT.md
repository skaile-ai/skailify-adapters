# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Everyone who takes part in it, in issues, pull requests, reviews and any other project space, is expected
to follow it.

In short: be respectful and considerate, welcome people of every background and level of experience,
give and accept constructive feedback gracefully, and focus on what is best for the project and the
people using it. Harassment, insults, personal or political attacks, and publishing other people's
private information are not acceptable.

## Reporting

Report behaviour that breaks this code to **security@skaile.ai**. The project uses one confidential
inbox for security and conduct reports; please start the subject line with "Conduct". Every report is
reviewed and investigated promptly and kept confidential. The maintainers decide on the response, from a warning to
a permanent ban from the project, following the Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
