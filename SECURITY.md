# Security policy

## Reporting a vulnerability

Please do not open a public issue, pull request or discussion for a security problem.

Email **security@skaile.ai** instead. Include:

- the adapter and version (or commit) affected,
- what an attacker can do, and the steps or a proof of concept to reproduce it,
- any fix or mitigation you have in mind.

We confirm receipt within three working days, keep you informed while we work on a fix, and credit you
in the release notes unless you ask us not to. Please give us a reasonable time to ship a fix before you
disclose the problem publicly.

## Supported versions

The adapters are pre-1.0. Security fixes go into the latest commit on `main` and the next release of the
affected adapter; older versions are not patched.
